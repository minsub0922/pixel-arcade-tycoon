# 플레이 영상 촬영 가이드 (30~60초, 사람 작업)

**규정**: 실제 플레이 화면 그대로. AI 조작·합성·타인 영상 금지. 편집은 컷·자막·타이틀 카드 수준까지만. YouTube 일부공개(unlisted), 댓글 닫기, 시크릿 창에서 링크 접근 테스트.

## 준비

- 녹화: macOS 화면수록(⌘⇧5) 또는 OBS, **1080p 이상 + 게임 사운드 포함**, 브라우저 전체화면(F11), 시크릿 창(코치마크 나오도록 저장 초기화 상태 권장 — 두 번째 테이크부터는 localStorage 삭제).
- 사전 리허설 1회: S1 경로를 손에 익히기. 60초 안에 담으려면 회의 말풍선은 1~2개 보고 스킵.

## 컷 구성 (60초 기준)

| 구간 | 내용 |
|---|---|
| 0–5s | **훅**: 오락실 영업 절정 장면(손님 붐빔+감정 칩+코인 이펙트) 선캡처 |
| 5–20s | 회의실: 기획 선택 → 팀원 말풍선 회의 → trade-off 결정 → 게임 카드 탄생(AI 네이밍) |
| 20–35s | 오락실: 배치 → 손님 유형별 반응(환호/실망 대비) → 피드백 카드·태그 |
| 35–50s | **와우**: 개선 결정 → 재방문 손님이 개선 언급 + 별점 상승 / 러너 직접 플레이 3~4초 |
| 50–60s | 타이틀 카드: 게임 로고 + "AI 팀과 만들고, AI 손님이 평가하다" + 팀명 |
